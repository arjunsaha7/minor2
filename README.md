Student Performance Analysis Using Python is a data analysis project that reads student marks from a CSV file and processes them using the Pandas and NumPy libraries. The program calculates subject-wise average, maximum, and minimum marks, along with total and average marks for each student. It also assigns grades based on performance and visualizes the results using Matplotlib bar charts to compare both student-wise and subject-wise performance. This project demonstrates basic data handling, statistical operations, and graphical representation using Python.
